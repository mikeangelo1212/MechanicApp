# About
Full stack pet project for keeping track of mechanic upkeep forklifts and mules in a Warehouse environment

### Why is it structured like this?
No Vue.JS routing but instead, the implementation of a PHP backend. This is because this little app is planned 
to be plug and play to an already existing environment that uses this structure
